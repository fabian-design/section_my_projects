Formulario de login HTML para la conexión con la base de datos

Actividad: Login y base de datos

En esta actividad vamos a preparar el archivo login.html, que contiene el formulario para ingresar un usuario y una contraseña. Este formulario se conectará con el archivo PHP que trabajaremos a continuación.

Dentro de <head> colocamos <meta charset="utf-8">, para definir la codificación de los caracteres, y <title>, para indicar el título de la página.

Dentro de <body> creamos un formulario con <form>. Sus atributos class, action, method y accept-charset permiten identificarlo, indicar a dónde se envían los datos, definir el método de envío y establecer la codificación. La estética de estas clases se verá a continuación.

El título <h2> muestra “Usuario”. Luego agregamos dos campos <input>: uno para el usuario o e-mail y otro para la contraseña. Las etiquetas <br> generan saltos de línea. Los campos también incluyen una clase para su estética y el atributo required, que exige completar el campo antes de enviar el formulario.

Finalmente, el botón <button type="submit"> permite enviar el formulario al presionar “Login”.

Importante: prestá especial atención al atributo action="php/login.php". Allí indicamos la carpeta php y el archivo login.php que recibirá los datos. Lo desarrollaremos en la siguiente actividad. No olvides cerrar el formulario con </form>.

Escribí la estructura HTML en el editor. Por ahora nos concentramos en el formulario; la conexión y validación con la base de datos se trabajarán desde PHP.
