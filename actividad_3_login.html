Formulario de login HTML para la conexión con la base de datos

Actividad: Login y base de datos

En esta actividad vamos a trabajar con los archivos login.html y login.php, que forman parte del sistema de autenticación de usuarios. El archivo HTML contiene el formulario de acceso, mientras que el archivo PHP procesa los datos ingresados y verifica las credenciales mediante una consulta a la base de datos.

En la primera imagen se presenta la estructura del formulario HTML, donde utilizamos etiquetas como <form>, <input> y <button> para permitir el ingreso de un usuario y una contraseña.

En la segunda imagen se encuentra el código PHP encargado de iniciar la sesión, recuperar los datos enviados mediante $_POST, realizar la consulta SQL y verificar si el usuario ingresado existe en la base de datos.

También se muestran las dos posibles respuestas del sistema: login correcto, cuando las credenciales son válidas, y login incorrecto, cuando los datos ingresados no coinciden.

Consigna: observá ambas referencias y transcribí los códigos en el editor, respetando la estructura, las etiquetas, las variables, las consultas SQL y las instrucciones de control utilizadas.
