Estructura HTML del bloque de proyectos

Actividad: Estructura HTML

Para comenzar a construir esta sección, primero vamos a crear una estructura HTML que contenga todos los elementos necesarios para mostrar nuestros proyectos.

La estructura comenzará con una sección principal, dentro de la cual tendremos el título “Mis Proyectos” mediante una etiqueta <h3>.

Luego agregaremos un bloque que contendrá las diferentes filas de proyectos y, dentro de cada fila, otro bloque correspondiente a cada proyecto.

Es importante diferenciar estos dos elementos: la fila será el bloque que contiene los proyectos, mientras que cada proyecto representará una columna dentro de esa fila.

Cada proyecto tendrá una etiqueta <a> que permitirá colocar el enlace hacia el proyecto que queremos abrir.

Dentro del enlace colocaremos una etiqueta <img> para mostrar la imagen correspondiente, indicando su ruta, es decir, la ubicación donde se encuentra guardada la imagen.

Finalmente, tendremos un bloque de información que contendrá la descripción del proyecto mediante una etiqueta <h4> y un párrafo <p>.

En esta primera etapa vamos a concentrarnos únicamente en construir y comprender la estructura HTML.

Los nombres de id y class que aparecen en el ejemplo se utilizarán posteriormente para aplicar los estilos mediante CSS. Por ahora no vamos a trabajar sobre ellos.

Los números 1, 2, 3, 4, 5, 6, 7 y 8 que aparecen como comentarios sirven únicamente para identificar las diferentes partes de la estructura. Posteriormente serán utilizados como referencia para aplicar los estilos en otro archivo CSS.
