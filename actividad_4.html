Actividad: Estructura HTML y estilos CSS del portfolio

En esta actividad vamos a trabajar con los archivos index.html y style.css, que forman parte del desarrollo de nuestro portfolio de proyectos. El archivo HTML define la estructura y el contenido de la página, mientras que el archivo CSS establece su diseño visual: distribución, tamaños, colores, imágenes y efectos.

En la referencia HTML se encuentra la estructura de la sección #portfolio, organizada mediante etiquetas y clases. Los números del 1 al 8 permiten identificar los diferentes niveles de anidamiento, desde la sección principal hasta la fila, cada proyecto, el enlace, la imagen y la información.

En la referencia CSS se encuentran las reglas que permiten dar estilo a cada uno de esos elementos. Observá cómo los selectores, por ejemplo #portfolio .fila .proyecto, identifican los elementos HTML y aplican propiedades que determinan su apariencia. También se incorporan efectos :hover para mostrar las imágenes en color y revelar la información de cada proyecto.

Consigna: transcribí en el editor los códigos HTML y CSS de las referencias, respetando las etiquetas, los atributos, los selectores, las propiedades y sus valores. Prestá atención a la estructura de los elementos y a la correspondencia entre las clases e identificadores utilizados en ambos archivos.
